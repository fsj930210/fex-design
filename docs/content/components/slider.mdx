## 何时使用

适合音量、比例、温度、价格范围、权重和阶段节点。精确数字输入应配合数值输入框；少量固定选项优先使用 Radio。

## CSS Variables

| 变量                          | 用途                         |
| ----------------------------- | ---------------------------- |
| `--slider-track-height`       | 水平轨道高度或垂直轨道宽度。 |
| `--slider-track-background`   | 未选中轨道背景。             |
| `--slider-range-background`   | 选中范围背景。               |
| `--slider-thumb-size`         | Thumb 尺寸。                 |
| `--slider-thumb-background`   | Thumb 背景。                 |
| `--slider-thumb-border-color` | Thumb 边框颜色。             |
