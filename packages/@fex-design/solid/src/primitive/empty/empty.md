# Solid Primitive Empty

Styled empty-state regions using Solid-native JSX attributes.

## Import

    import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from '@fex-design/solid/primitive/empty'

## API

The regions add no state props. Native JSX attributes, events, class, style, ARIA attributes, and children pass through to their hosts.

`basic`, `content`, `image`, and `direction` match UI Empty visually.
