title: Tag
description: 展示分类、属性和状态信息，并支持可关闭的快捷组合。
---

## 何时使用

用于展示简短的分类、属性或状态，例如文章标签、商品特征和筛选条件；也可用于展示可移除的已选项目。

## API

<ApiContainer>
<ApiSection layer="ui" title="UI API" description="UI Tag 的可关闭快捷组合与结构化样式。">
  <ApiComposition layer="ui">
    设置 `closable` 显示关闭按钮，可通过当前框架的内容入口替换关闭图标。

    ```text
    Tag
    ├── content
    └── close (closable = true)
    ```

  </ApiComposition>
</ApiSection>

<ApiSection layer="primitive" title="Primitive API">
  <ApiComposition layer="primitive">
    ```text
    Tag
    └── TagAction (optional)
    ```

    `TagAction` 是独立操作按钮，由调用方决定它表示关闭、编辑、更多或其他行为；组件本身不修改 Tag 状态。

  </ApiComposition>
</ApiSection>
</ApiContainer>
