## Primitive 与 UI

Primitive 提供 `SkeletonBlock`、`SkeletonText`、`SkeletonAvatar`、`SkeletonButton`、`SkeletonInput` 和 `SkeletonImage`。Text 始终只表示一行。

UI 重新导出全部 Primitive，并增加组合版 `Skeleton`：根据 avatar、title、paragraph 快速生成结构，也可通过 loading、子内容和自定义 placeholder 作为加载容器。

## CSS Variables

`SkeletonButton` 默认通过 `--skeleton-button-height-sm`、`--skeleton-button-height-md`、`--skeleton-button-height-lg` 回退到对应的全局 `--height-*`；`SkeletonInput` 通过 `--skeleton-input-height-md` 回退到全局 `--height-md`。这些组件级变量只调整 Skeleton 预设，不会改变 Button 或 Input。
