# React Primitive Empty

用于自由组合媒体、标题、描述和操作内容的有样式空状态区域。

## 引入

    import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from '@fex-design/react/primitive/empty'

## 组件与 API

除 `EmptyDescription` 继承原生 `p` 外，各布局组件继承原生 `div`；原生属性、事件、class、style、ARIA 属性和 children 均可透传。组件族不增加状态属性。

`basic`、`content`、`image`、`direction` 与 UI Empty 保持相同展示。
