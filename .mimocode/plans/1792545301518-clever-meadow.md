# 表单显示状态契约迁移 —— 剩余执行计划

## 契约（已确认，不再讨论）

- **错误视觉 = 原生 `aria-invalid="true"`**，必须落在有语义的控件元素（input/combobox/textarea/button[role=slider] 等）；包装表面用 `has-[[aria-invalid=true]]` 命中。
- **警告视觉 = 呈现属性 `data-warning="true"`**（值必须是字符串 `"true"`），落在画边框的表面元素上（`data-[warning=true]` 自命中）。
- 不设 `status` 或任何显示态 prop；`invalid` 布尔 prop 保留（语义对齐 aria-invalid 的简写）。Field 不动。progress/steps/timeline/upload/transfer 的 status/validation 是真业务态，**不碰**。
- 共享配方：`components-styles/src/form-treatment.ts` 的 `formTreatment(variant, accent)`；switch/slider/textarea 有各自特例写法（已定型）。
- React 参考实现在 `components/react/src/primitive/select/`（root 捕获属性 → context 携 `ariaInvalid`/`dataWarning` → trigger 分流：表面 div 放 data-warning、内层控件放 aria-invalid）。

## 已完成（勿重做）

- 样式层（`components/styles/src/`）：`form-treatment.ts` + exports；input/select/checkbox/radio×2/switch/slider/textarea/cascader 已切到新选择器，`data-[status=...]` 已清除。
