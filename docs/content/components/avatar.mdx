## Primitive 与 UI

Primitive 适合自行组合图片、fallback、状态和头像组。

UI 提供开箱即用的头像，并为头像组增加自动截断。

## CSS Variables

Avatar 始终保持等宽高，因此使用单个尺寸变量，不分别暴露 width 和 height。变量可写在单个 Avatar、AvatarGroup 或业务容器上。例如在 AvatarGroup 上设置 `--avatar-size: 3rem`，组内头像和默认溢出节点都会变为 `3rem × 3rem`；设置 `--avatar-group-overlap: 1rem` 可调整相邻头像的重叠距离。

| 变量                     | 默认值                      | 说明                                                                 |
| ------------------------ | --------------------------- | -------------------------------------------------------------------- |
| `--avatar-size`          | 由 `size` 决定，默认 `2rem` | 覆盖当前作用域内 Avatar 与溢出节点的宽高；`size="md"` 为组件默认值。 |
| `--avatar-size-sm`       | `1.5rem`                    | `size="sm"` 的默认宽高。                                             |
| `--avatar-size-md`       | `2rem`                      | `size="md"` 的默认宽高。                                             |
| `--avatar-size-lg`       | `2.5rem`                    | `size="lg"` 的默认宽高。                                             |
| `--avatar-group-overlap` | `0.75rem`                   | AvatarGroup 相邻项目的重叠距离。                                     |
