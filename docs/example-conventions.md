# 示例 Demo 目录规范

组件的 `examples/` 目录和官网 Demo 列表使用同一套顺序和命名。

## 顺序

1. `basic`：基本用法必须是第一个示例；新增组件统一使用 `basic`。`simple` 只表示某个组件的简洁变体，不能代替基本用法。
2. 中间示例按功能分组：形态与尺寸、内容与选项、范围与布局、禁用与校验、受控与状态、组合与替换。每组内按目录名稳定排序。
3. 方向示例使用 `direction`，放在倒数区域，用标题 `LTR 与 RTL`。
4. CSS 变量示例使用 `css-variables`，放在方向示例之后。
5. 结构化样式示例使用 `semantic-styles`，放在 CSS 变量之后。
6. 独立逻辑示例标题使用对应的 `useXxx` API 名称，放在最后；示例必须使用公开逻辑入口手写一个完整的自定义组件 DOM，不能只放几个按钮。

`rtl`、`ltr`、`reading-direction`、`styles`、`styling`、`structured`、`structured-styles` 和 `css-vars` 不再作为新目录名。历史目录可以在迁移时改为上面的规范名，页面排序器暂时兼容这些旧 ID。

## 文案

当前官网示例标题、说明和目录统一使用中文；代码中的 API 名称、CSS 变量名和 `LTR`、`RTL` 等协议词保留原文。国际化接入后，文案放入语言资源，目录 ID 和源码文件名保持不变，不随语言切换。
