## CSS Variables

`SkeletonButton` 默认通过 `--skeleton-button-height-sm`、`--skeleton-button-height-md`、`--skeleton-button-height-lg` 回退到对应的全局 `--height-*`；`SkeletonInput` 通过 `--skeleton-input-height-md` 回退到全局 `--height-md`。这些组件级变量只调整 Skeleton 预设，不会改变 Button 或 Input。
