# Svelte UI Checkbox

由 Primitive parts 组合而成的快捷 Checkbox 和 CheckboxGroup。UI 与 Primitive 使用相同示例，另有 semantic-styles。Checkbox 使用原生 change；Group 只管理平级 value 数组。

## CSS Variables

与 Primitive 共用 --checkbox-size、--checkbox-background、--checkbox-border-color、--checkbox-checked-background、--checkbox-checked-border-color、--checkbox-indicator-color、--checkbox-ring-color、--checkbox-content-gap。
