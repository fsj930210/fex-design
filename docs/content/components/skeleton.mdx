## Primitive 与 UI

Primitive 提供 `SkeletonBlock`、`SkeletonText`、`SkeletonAvatar`、`SkeletonButton`、`SkeletonInput` 和 `SkeletonImage`。Text 始终只表示一行。

UI 重新导出全部 Primitive，并增加组合版 `Skeleton`：根据 avatar、title、paragraph 快速生成结构，也可通过 loading、子内容和自定义 placeholder 作为加载容器。
