## Primitive 与 UI

Primitive 提供带样式的 TooltipRoot、TooltipTrigger、TooltipPortal、TooltipContent 和 TooltipArrow，用于自由组合。UI Tooltip 自动组合 Portal、Content 与默认箭头，通过 `title` 快速提供说明。

## 何时使用

用于解释图标按钮、缩略文本或不明显的操作。Tooltip 内容保持简短且不包含按钮、链接和表单；需要交互内容时使用 Popover。

## CSS Variables

Primitive `TooltipContent` 与 UI `Tooltip` 都支持 `color` 设置背景与箭头颜色；前景色继续由默认 token 或 `--tooltip-foreground` 控制，不进行运行时颜色计算。
