# React UI Empty

基于 Primitive 区域组成的快捷 Empty。

## 引入

    import { Empty } from '@fex-design/react/ui/empty'

## API

`image` 接受 ReactNode、图片地址或 `null`，未传时显示内置图形，`null` 隐藏媒体；`title` 是标题，`description` 是说明，`children` 渲染到 EmptyContent。`classNames` 和 `styles` 可定制 root、header、image、title、description、content。

`basic`、`content`、`image`、`direction` 与 Primitive 展示一致；`styling` 展示 UI 的结构化样式。
