Badge 用于展示紧凑的状态、分类或数量信息。Primitive 只提供徽标本身，UI 提供常用的附着式快捷写法。

## Primitive 与 UI

Primitive 提供可独立使用的徽标、小圆点、Ribbon 和徽标组，不负责附着定位。

UI 在此基础上增加右上角附着、位置偏移和结构化样式；徽标组直接复用 Primitive。
