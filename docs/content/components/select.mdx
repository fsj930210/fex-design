## Primitive 与 UI

Primitive 提供 `SelectRoot`、`SelectTrigger`、`SelectValue`、`SelectContent`、`SelectItem`、`SelectGroup`、`SelectLabel` 和 `SelectSeparator`。Root 接收动态 `items`，Content 内部负责过滤、键盘导航和真正的虚拟渲染；Item 挂载时不做注册。

UI `Select` 是 Ant Design 风格的快捷组合，接收任意对象数组，并通过 `fieldNames.value` 与 `fieldNames.label` 映射字段。`disabled` 仍是项目自身的布尔字段，分组使用带 `options` 的组对象或 Primitive 的 `SelectGroup`。

TagsInput 是独立组件，不属于 Select；Select 只支持单选和多选已有项目。AutoComplete 继续处理输入建议场景。

## CSS Variables

Select 不新增组件变量。Trigger 使用 Input 的变量和结构化样式，Content 使用 Popover/Floating 的变量；虚拟行高由 `virtual.itemHeight` 明确控制。
