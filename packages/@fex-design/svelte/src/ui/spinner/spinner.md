# Svelte UI Spinner

Recommended entry for standalone indicators and content loading.

## Import

    import { Spinner, SpinnerContainer } from '@fex-design/svelte/ui/spinner'

## Examples

`basic`, `sizes`, `custom-indicator`, `container`, `text`, and `styling` cover standalone indicators, custom indicator content, content loading, description text, and semantic styling.

## API

`Spinner` accepts `size` and a children snippet for custom indicator content. `SpinnerContainer` accepts `spinning`, `size`, `text`, `indicator`, `classNames`, and `styles`; undefined, false, and true represent standalone, content-only, and content-with-overlay output respectively.
