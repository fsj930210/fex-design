## Primitive 与 UI

Primitive 提供保持内容宽高比的基础容器。

UI 不增加能力，直接复用 Primitive。

## 使用场景

适合图片、视频、地图或卡片媒体区域。将媒体内容设置为 `size-full object-cover`，即可填充容器。
