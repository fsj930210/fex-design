Alert 用于在当前页面上下文中传达明确的反馈状态。`type` 表达消息语义并决定内置图标与状态色，`variant` 控制 filled、outlined、solid 三种视觉层级。

## Primitive 与 UI

Primitive 提供 styled `Alert`、`AlertIcon`、`AlertTitle`、`AlertDescription` 和 `AlertAction`，不自动创建图标、关闭按钮或保存显隐状态。

UI 将这些部件封装为一个 `Alert`，提供内置状态图标、可关闭行为、自定义 icon/action 以及 `classNames` / `styles` 语义化定制。
