## 何时使用

- 任务执行需要较长时间，需要向用户反馈明确的完成进度时。
- 展现当前操作在整体中所占的百分比（如上传、下载、存储空间占用等）。
- 表达任务生命周期：尚未开始、进行中、成功或失败。

## CSS Variables
