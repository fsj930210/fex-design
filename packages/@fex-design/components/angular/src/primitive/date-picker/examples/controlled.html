受控：value / open

外部按钮可设置、清空选择值，也可控制面板开关。

外部值：{{ value().start?.toString() ?? '未选择' }} → {{ value().end?.toString() ?? '未选择' }}；面板：{{ open() ? '打开' : '关闭' }}

非受控：defaultValue

defaultValue 仅初始化读取；上方按钮更新外部值后，这里的选择保持不变。

选择结果：{{ uncontrolledValue().start?.toString() ?? '未选择' }} → {{ uncontrolledValue().end?.toString() ?? '未选择' }}
