title: Spinner

---

## 何时使用

用于无法确定完成进度的短时等待，例如异步字段加载、列表刷新或表格更新。独立等待使用 Spinner；已有内容需要刷新时使用 SpinnerContainer。首次加载且需要预留内容结构时使用 Skeleton；没有数据时使用 Empty。

## API

<ApiContainer>
<ApiSection
  layer="ui"
  title="UI API"
  description="UI Spinner 的独立指示器和内容 loading 容器属性。"
>
  <ApiComposition layer="ui">
    ```text
    SpinnerContainer
    ├── children
    └── overlay (spinning = true)
        ├── Spinner
        └── SpinnerText (optional)
    ```

    UI `SpinnerContainer` 负责 loading 状态、遮罩和默认居中布局；`Spinner` 可独立使用。

  </ApiComposition>
</ApiSection>

<ApiSection
  layer="primitive"
  title="Primitive API"
>
  <ApiComposition layer="primitive">
    ```text
    SpinnerContainer
    ├── children
    └── SpinnerOverlay
        ├── Spinner
        └── SpinnerText
    ```

    Primitive 不负责 `spinning`，调用方拥有条件渲染和布局。

  </ApiComposition>
</ApiSection>
</ApiContainer>
