# Vue UI Spinner

Recommended entry for standalone indicators and local content loading.

## Import

    import { Spinner, SpinnerContainer } from '@fex-design/vue/ui/spinner'

## API

`Spinner` accepts `size` and a default slot for a custom indicator. `SpinnerContainer` accepts `spinning`, `size`, and `text`; when loading it keeps the content and displays the indicator above it. Use the `indicator` slot to replace the default icon.

## Examples

`basic`, `sizes`, `custom-indicator`, `container`, `text`, and `styling` cover the public API.
