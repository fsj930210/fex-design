## Primitive 与 UI

Button 提供按钮、图标和按钮组能力。

- **Primitive**：提供 `Button`、`ButtonIcon` 和 `ButtonGroup`。
- **UI**：提供按钮的快捷属性和预设外观。

## 何时使用

Button 用于触发即时操作。页面跳转使用链接；开关状态使用 Toggle；互斥选择使用 ToggleGroup、Radio 或 Tabs。

## Composition

`ButtonIcon` 用于图标内容，`ButtonGroup` 用于组织相关按钮。

```text
Button
└── ButtonIcon (optional)

ButtonGroup
├── Button
└── Button
```

## CSS Variables

CSS Variables 可直接写在单个 Button 上完成实例级覆盖，也可写在局部容器或主题根节点，让其中所有 Button 继承。尺寸变量可以覆盖某个 size 的最终结果，颜色变量用于覆盖当前 variant 使用的语义色组。
