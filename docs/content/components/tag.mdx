Tag 用于承载简短的分类、属性或状态文本。`color` 支持五种语义色和任意 CSS 颜色，`variant` 控制 filled、solid、outlined 三种视觉层级。

## Primitive 与 UI

Primitive 提供 styled `Tag` 和带默认关闭图标的 `TagClose`。`TagClose` 使用原生按钮属性和事件，内容可以完全替换默认图标。

UI 在 Primitive 上增加 `closable`、关闭事件以及 `classNames` / `styles` 的 root、close 结构化定制，不保存标签显隐状态。
