## 何时使用

需要在头像、图标或入口旁展示未读数量、待办提醒或状态标记时使用，也可独立展示简短的数量与状态信息。

## API

<ApiContainer>
<ApiSection layer="ui" title="UI API" description="UI Badge 的快捷附着用法。">
  <ApiComposition layer="ui">
    `Badge` 将数量或状态标记附着到内容上；`BadgeRibbon` 用于容器边缘的缎带，`BadgeGroup` 用于组织多个徽标。

    ```text
    Badge
    ├── content
    └── indicator

    BadgeRibbon
    └── content

    BadgeGroup
    ├── Badge
    └── Badge
    ```

  </ApiComposition>
</ApiSection>

<ApiSection
  layer="primitive"
  title="Primitive API"

  <ApiComposition layer="primitive">

    ```text
    Badge
    └── BadgeDot (optional)

    BadgeRibbon
    └── content

    BadgeGroup
    ├── Badge
    └── Badge
    ```

  </ApiComposition>
</ApiSection>
