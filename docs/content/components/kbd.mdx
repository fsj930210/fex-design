## Primitive 与 UI

`Kbd` 是带基础样式的原生 `kbd` 封装，`KbdGroup` 用于组合多个按键。UI 层不增加额外交互，直接复用 Primitive。

## 何时使用

Kbd 用于展示键盘按键、快捷键组合和按钮对应的快捷键提示。

## Composition

使用下面的组合方式构建 `Kbd` 和 `KbdGroup`：

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```
