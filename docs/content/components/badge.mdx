## 何时使用

Badge 用于展示紧凑的状态、分类或数量信息。Primitive 只提供徽标本身，UI 提供常用的附着式快捷写法。

## API

<ApiContainer>
<ApiSection layer="ui" title="UI API" description="UI Badge 的快捷附着用法。">
  <ApiComposition layer="ui">
    UI `Badge` 自己创建附着指示器或 Dot；`BadgeRibbon` 提供 Ribbon 快捷组合，`BadgeGroup` 直接复用 Primitive。

    ```text
    Badge
    ├── content
    └── indicator

    BadgeRibbon
    └── content

    BadgeGroup
    ├── Badge
    └── Badge
    ```

  </ApiComposition>
</ApiSection>
