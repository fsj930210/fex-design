## Primitive 与 UI

Primitive 提供可自由组合的 `InputRoot`、`InputControl`、Prefix、Suffix、Addon、Clear 和 `InputGroup`。UI 提供开箱即用的 `Input`、`InputPassword` 与 `InputSearch`，并直接复用 `InputGroup`。

浮动 Label 属于 Field，不由 Input 负责；普通 Input 的 Prefix 与 Suffix 只承载内容，只有 InputSearch 会把其搜索位置包装成可触发搜索的内部按钮。

## 何时使用

Input 用于接收单行文本。密码使用 InputPassword，具有明确提交意图的搜索使用 InputSearch；多行文本使用 Textarea，带 Label、说明和验证信息的完整表单项使用 Field。

## CSS Variables

CSS Variables 只负责基础视觉和尺寸；hover、focus-within、variant 与 `aria-invalid` 使用选择器覆盖，避免为每个状态增加变量。`className`/`class` 落在真实 Input Root，内部区域可通过 `classNames`、`styles` 或 `data-slot` 定位。

`InputGroup` 只为直接子元素提供默认连接圆角，不限定子元素类型，也不使用 `!important`。在 Group 上设置 `[--input-group-radius:0px]` 可移除整组外圆角，设置为其他值可更换整组圆角；在某个直接子元素上设置同一变量，则只局部覆盖该元素的外侧圆角。
