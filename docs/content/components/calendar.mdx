## 何时使用

需要直接使用完整日历时使用 UI Calendar；需要替换默认布局、组合自己的 Header、Grid、Cell 或 Footer 时使用 Primitive Calendar。浏览年月与选择日期分离，onChange 只提交日期值。两层示例覆盖相同场景和相同数据，UI 使用快捷组合，Primitive 使用原子部件组合。
