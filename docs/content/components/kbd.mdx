## Primitive 与 UI

Primitive 提供按键和按键组合的基础样式。

UI 不增加能力，直接复用 Primitive。

## 何时使用

Kbd 用于展示键盘按键、快捷键组合和按钮对应的快捷键提示。

## Composition

使用下面的组合方式构建 `Kbd` 和 `KbdGroup`：

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```
