# Angular UI Empty

基于原生 div 宿主的快捷 Empty。

## 引入

    import { Empty } from '@fex-design/angular/ui/empty'

使用 `<div empty>`。输入包括 `image: string | TemplateRef | null`、`title`、`description`、`classNames` 和 `styles`，投影内容进入 EmptyContent。`image` 未定义时使用内置图形，`null` 隐藏媒体。四个公共示例与 Primitive 展示一致，`styling` 为 UI 专属。
