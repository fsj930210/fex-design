# Vue UI Spinner

推荐用于独立指示器和局部内容 loading 的入口。

## 导入

    import { Spinner, SpinnerContainer } from '@fex-design/vue/ui/spinner'

## API

`Spinner` 支持 `size` 和用于替换指示器的默认 slot。`SpinnerContainer` 支持 `spinning`、`size`、`text`；加载时保留内容并在其上方显示指示器。使用 `indicator` slot 可替换默认图标。

## 示例

`basic`、`sizes`、`custom-indicator`、`container`、`text`、`styling` 覆盖公开 API。
