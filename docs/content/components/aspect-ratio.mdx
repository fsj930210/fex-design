## Primitive 与 UI

`AspectRatio` 是带基础样式的 `div` 容器，通过 `ratio` 保持内容宽高比。UI 层不增加额外交互，直接复用 Primitive，并继承原生 `div` 属性、事件和内容。

## 使用场景

适合图片、视频、地图或卡片媒体区域。将媒体内容设置为 `size-full object-cover`，即可填充容器。
