## 何时使用

Tag 用于承载简短的分类、属性或状态文本。`color` 支持五种语义色和任意 CSS 颜色，`variant` 控制 filled、solid、outlined 三种视觉层级。

## API

<ApiContainer>
<ApiSection layer="ui" title="UI API" description="UI Tag 的可关闭快捷组合与结构化样式。">
  <ApiComposition layer="ui">
    UI `Tag` 通过 `closable` 创建关闭区域；自定义 close icon 使用当前框架的原生内容入口，不需要手动组合 `TagAction`。

    ```text
    Tag
    ├── content
    └── close (closable = true)
    ```

  </ApiComposition>
</ApiSection>

<ApiSection layer="primitive" title="Primitive API" description="Primitive Tag 与 TagAction 的公开属性。">
  <ApiComposition layer="primitive">
    ```text
    Tag
    └── TagAction (optional)
    ```

    `TagAction` 是独立操作按钮，由调用方决定它表示关闭、编辑、更多或其他行为；组件本身不修改 Tag 状态。

  </ApiComposition>
</ApiSection>
</ApiContainer>
