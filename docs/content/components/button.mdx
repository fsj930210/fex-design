## 何时使用

Button 用于触发即时操作。页面跳转使用链接；开关状态使用 Toggle；互斥选择使用 ToggleGroup、Radio 或 Tabs。

## CSS Variables

Button 默认从全局 `--height-sm`、`--height-md`、`--height-lg` 取得高度，md 图标从 `--icon-size-md` 取得尺寸。只调整 Button 时使用 `--button-height-*` 和 `--button-icon-size-*`；单个实例可继续用 `--button-height`、`--button-icon-size` 覆盖最终结果。变量可写在组件、局部容器或主题根节点上。
