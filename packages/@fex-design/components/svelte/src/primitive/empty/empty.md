# Svelte Primitive Empty

Styled empty-state regions using Svelte 5 components and snippets.

## Import

    import Empty from '@fex-design/svelte/primitive/empty'
    import EmptyHeader from '@fex-design/svelte/primitive/empty-header'

The remaining parts use `primitive/empty-media`, `primitive/empty-title`, `primitive/empty-description`, and `primitive/empty-content`.

## API

Each component accepts its native element attributes and a `children` Snippet.

## Examples

`basic`, `content`, `image`, and `direction` match UI Empty in copy, layout, and final appearance.

## Direction

Native `dir` controls inherited LTR and RTL layout.

## Accessibility

Add live-region semantics only when dynamic updates require announcement.
